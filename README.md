# Wordpress AI workspace

This project is made for VsCode with AI agents like Cline or Roo Code.

.clinerules in root offer basic instructions and AI should suggest it's updated based on real state of the project and its contents.

This is a template - this project should be cloned and configured for your project. There's an install step and install instructions the AI has in ./prompts/INSTALL.md based on it can help configure this workspace so that it can download current projects via ftp or ssh, start tracking them in Git and perhaps offer GitHub integrations with gh CLI, it should be able to download the database and run the project locally, preferably in docker. 
We should be able to have actions/pipelines for deployment, use git branches for tracking development, and walk the user through all this 2025 modern scaffolding where everything can be explained and configured and plugged in using AI plugin in VSCode.
