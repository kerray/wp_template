# vibe-tools Integration

vibe-tools is a CLI tool that allows you to interact with AI models and other tools.
vibe-tools is installed on this machine and available to execute.

## Quick Reference

```bash
vibe-tools web "question"           # Web search (Perplexity)
vibe-tools repo "question"          # Repository analysis (Gemini)
vibe-tools plan "task description"  # Implementation planning
vibe-tools browser open <url>       # Browser automation (Stagehand)
vibe-tools doc                      # Generate documentation
```

## Commands

### Web Search
```bash
vibe-tools web "<your question>"
```
Get answers from the web using Perplexity. Include context and goals for best results.

### Repository Analysis
```bash
vibe-tools repo "<your question>" [--subdir=<path>] [--from-github=<user/repo>]
```
Context-aware answers about this repository using Gemini.

### Implementation Planning
```bash
vibe-tools plan "<query>"
```
Generate focused implementation plans. Uses multiple AI models to identify files and create detailed plans.

### Browser Automation
```bash
vibe-tools browser open <url> [options]
vibe-tools browser act "<instruction>" --url=<url>
vibe-tools browser observe "<instruction>" --url=<url>
vibe-tools browser extract "<instruction>" --url=<url>
```

### Documentation Generation
```bash
vibe-tools doc [--output docs.md]
```

### GitHub Integration
```bash
vibe-tools github pr [number]       # Get PRs
vibe-tools github issue [number]    # Get issues
```

### YouTube Analysis
```bash
vibe-tools youtube "<url>" [--type=<summary|transcript|plan|review>]
```

### MCP Commands
```bash
vibe-tools mcp search "<query>"     # Search MCP Marketplace
vibe-tools mcp run "<query>"        # Execute MCP tools
```

## Common Options

```bash
--provider=<provider>    # openai, anthropic, perplexity, gemini, openrouter, modelbox, xai
--model=<model>          # Specific model to use
--max-tokens=<number>    # Control response length
--save-to=<file>         # Save output to file
--debug                  # Show detailed logs
```

## Nicknames

- **Gemini** = `vibe-tools repo`
- **Perplexity** = `vibe-tools web`
- **Stagehand** = `vibe-tools browser`

## Browser Command Notes

- Commands are stateless unless using `--connect-to`
- Use `--url=current` to stay on current page
- Multi-step workflows: use pipe separator `|`
- Video recording: `--video=<directory>`
- DO NOT use "wait" in browser act commands
